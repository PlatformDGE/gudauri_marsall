# Daily Rent · Gudauri Marshall

Список покупок и бюджет для квартиры в Гудаури.

- Сайт: `index.html`, размещается на GitHub Pages.
- Данные: закрытая Google Таблица и папка на Google Диске. В этом репозитории данных и ключей нет.
- Связь: скрипт `apps-script/Code.gs` проверяет ключ из ссылки. Здесь лежит шаблон; рабочая копия с ключами хранится в самой таблице.
- Доступ: две секретные ссылки. Команда редактирует список и загружает чеки. Собственник видит только отчёт: бюджет, покупки, чеки и план. Чтобы отозвать ссылку, поменяйте ключ в скрипте и разверните новую версию.
